# Naveen Singh Portfolio

Static portfolio website tailored to Quality Technologist, Laboratory Technologist and Pharmaceutical Quality Technologist roles.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. GitHub will provide the public site address within a few minutes.
